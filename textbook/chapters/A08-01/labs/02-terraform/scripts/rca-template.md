# 事故复盘（RCA）——模板

> 每一句结论都标明证据来源；没有证据的写“未知”，不要用推断填空。

| 字段 | 内容 | 证据 |
|---|---|---|
| 摘要 | 用户看到了什么；结论的置信度 | |
| 影响 | 哪些用户、功能、区域；起止时间写成区间（探针间隔带来的不确定性） | probes.jsonl |
| 时间线（UTC） | 变更、首次失败观测、告警、开始处置、恢复、首次成功观测 | CloudTrail、探针、告警 |
| 直接原因 | 哪条技术机制直接导致故障 | 事件 + 现状 + 同条件复测 |
| 促成条件 | 系统为何允许它发生（例如：可以绕过 IaC 直接改生产安全组） | 权限、流程 |
| 检测缺口 | 为什么没有更早发现（首次失败观测与首次告警的时间差） | |
| 被排除的假设 | 每个假设被哪条观察证伪 | ir.py dx 输出 |
| 行动项 | 每项写负责人、截止日期、可验证的验收标准 | |
